## Опис роботи

У межах лабораторної роботи реалізовано та порівняно два базові алгоритми пошуку елемента в масиві:
1. **Лінійний пошук (`linearSearch`)** — послідовно перевіряє елементи масиву з початку до кінця. Працює як із відсортованими, так і з невідсортованими даними.
2. **Бінарний пошук (`binarySearch`)** — ітеративно ділить відсортований масив навпіл, відкидаючи половину елементів на кожному кроці. Вимагає попереднього впорядкування даних.

Обидві функції рахують кількість виконаних порівнянь (`comparisons`) і коректно обробляють граничні випадки (порожній масив та масив із одного елемента).

## Як запустити проєкт

1. Переконайтеся, що на комп'ютері встановлено **Python 3** (версії 3.8 або новішої):
   ```bash
   python --version
   ```

2. Клонуйте репозиторій та перейдіть у папку лабораторної роботи:
   ```bash
   git clone <посилання-на-ваш-репозиторій>
   cd lab04
   ```

3. Запустіть скрипт у терміналі:
   ```bash
   python lab04.py
   ```
   *(На Linux або macOS може знадобитися команда `python3 lab04.py`)*

## Що виконується під час запуску

Після запуску `lab04.py` у консоль автоматично виводяться результати (знайдений індекс та кількість порівнянь) для обох алгоритмів:

* **Частина 2 (Перевірка на відсортованому масиві `sortedData`):**
  1. Пошук першого елемента (`3`)
  2. Пошук останнього елемента (`71`)
  3. Пошук середнього елемента (`31`)
  4. Пошук відсутнього елемента, меншого за мінімальний (`1`)
  5. Пошук відсутнього елемента, більшого за максимальний (`99`)
  6. Пошук відсутнього елемента між сусідніми значеннями (`50`)
  7. Пошук у масиві з одного елемента (`[42]`)
  8. Пошук у порожньому масиві (`[]`)

* **Частина 3 (Експеримент):**
  * Запуск лінійного та бінарного пошуку для значення `55` на початковому **невідсортованому** масиві `data` для демонстрації некоректної роботи бінарного пошуку без попереднього сортування.
